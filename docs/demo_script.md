**2. For delivered orders purchased in 2018, what were the total freight value and the total amount paid?**
v1 (fails):
```sql
SELECT 
    SUM(oi.freight_value) AS total_freight,
    SUM(op.payment_value) AS total_paid
FROM orders o
JOIN order_items oi      ON o.order_id = oi.order_id
JOIN order_payments op   ON o.order_id = op.order_id
WHERE o.order_status = 'delivered'
  AND strftime('%Y', o.order_purchase_timestamp) = '2018';
```
Result:
```text
total_freight  total_paid
     1284258.4 10841161.92
```
v4 (passes):
```sql
WITH freight_per_order AS (
    SELECT order_id, SUM(freight_value) AS total_freight
    FROM order_items
    GROUP BY order_id
), paid_per_order AS (
    SELECT order_id, SUM(payment_value) AS total_paid
    FROM order_payments
    GROUP BY order_id
)
SELECT 
    ROUND(SUM(f.total_freight), 2) AS total_freight,
    ROUND(SUM(p.total_paid), 2) AS total_paid
FROM orders o
JOIN freight_per_order f ON o.order_id = f.order_id
JOIN paid_per_order p ON o.order_id = p.order_id
WHERE o.order_status = 'delivered'
  AND strftime('%Y', o.order_purchase_timestamp) = '2018';
```
Result:
```text
total_freight  total_paid
    1233459.65   8452975.2
```
