# Limitations

_Generated by `python eval/stats.py --split test` from the latest test results. Re-run it after new runs._

- **Small test set.** The held-out split has 40 questions, so one question is 2.5 percentage points.
  95% bootstrap intervals are wide: the widest is v1 at 69.2–92.5%. Differences smaller than that should not be read as real.
- **Repeats are not independent samples.** All runs use temperature 0, so the 3 repeats of a question are nearly the same answer. Per-repeat accuracy ranges: v0 7.5–7.5%; v1 80.0–82.5%. Questions whose result changed between repeats: v0 0 of 40; v1 1 of 40. The effective sample size is the number of questions (40), not questions × repeats, so the confidence intervals and the McNemar test resample or pair by question.
- **Gold queries are not verified.** All 60 gold queries were drafted with the help of Claude and are marked `verified: false` until a team member checks them. A wrong gold query moves every version's score.
- **Business-rule assumptions.** "Sales" = delivered orders, and "revenue" = SUM(price) per product, category or seller. The v2–v4 prompts and the gold queries use the same definitions, which favours v2–v4 when a question is read another way. The team has not confirmed these yet.
- **Error labels are drafts.** Failure categories were proposed by Claude from the SQL and need a human check.
- **One database, English only.** Every question is about the Olist schema and is written in English. Nothing here says how the prompts work on other schemas or languages.
- **One main model.** gpt-oss-120b on Groq, one setting. The gpt-oss-20b check is a single run.
- **Prompt text changes more than one thing at a time.** v2 adds the CREATE TABLE text and the business rules together, so their separate effects are not measured.
- **v4 shares v3's first answer.** v4 differs from v3 only by the repair loop, so v3 vs v4 measures repair alone.
- **Execution accuracy can pass a wrong query** that happens to return the same rows as the gold query, and fails a correct query that formats a value differently (e.g. a percentage vs a fraction).
